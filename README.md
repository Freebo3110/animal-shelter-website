# Animal Shelter Website

This project is a web application for an animal shelter built using **React**. The website aims to provide a platform for users to explore adoptable animals, learn more about the shelter, and get involved in supporting animal welfare.

## Features

- **Adoptable Animals**: View profiles of animals available for adoption, including pictures, descriptions, and adoption status.
- **Animal Search**: Search and filter animals based on type (dogs, cats, etc.), breed, size, age, and other characteristics.
- **Shelter Information**: Learn more about the shelter’s mission, location, and contact details.

## Technologies Used

- **React**: JavaScript library for building the user interface.
- **React Router**: For managing routing and navigation between pages.
- **CSS**: For styling the website.
- **React Hooks**: To manage state and side effects in functional components.
